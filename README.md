# OSI Model

The OSI model is a conceptual framework that explains how data travels across a network.

| Layer | Name | Example |
|-------|------|---------|
| 7 | Application | HTTP, FTP |
| 6 | Presentation | Encryption |
| 5 | Session | Session management |
| 4 | Transport | TCP, UDP |
| 3 | Network | IP |
| 2 | Data Link | Ethernet |
| 1 | Physical | Cables |
